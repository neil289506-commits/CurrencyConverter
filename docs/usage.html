Usage

使用方式

第一次啟動預設為 USD → TWD、金額 1000,之後沿用你上次的設定。

操作步驟

選擇來源幣別

選擇或搜尋來源幣別。

輸入金額

輸入要換算的金額。

選擇目標幣別

選擇或搜尋目標幣別。

查看結果

查看換算結果與顯示的匯率。

交換方向

按交換鈕對調來源與目標。

立即更新

按「Refresh」立即取得新匯率。

顯示規則

  • 來源與目標相同時,匯率為 1,不會發出網路請求。
  • 零小數位幣別取整數;多數幣別顯示兩位小數;定義為三位小數的幣別顯示三位。
  • 匯率時間戳記取自匯率端點回傳的值(若有)。
