💱 CurrencyConverter首頁使用方式匯率資料建置

使用方式

  1. 選擇或搜尋來源幣別。
  2. 輸入金額。
  3. 選擇或搜尋目標幣別。
  4. 查看換算結果與顯示的匯率。
  5. 按交換鈕對調方向。
  6. 按「Refresh」立即取得新匯率。

第一次啟動時，預設是 USD → TWD，金額 1000；之後會沿用你上次的設定。

顯示規則

  • 來源與目標相同時，匯率為 1，不會發出網路請求。
  • 零小數位幣別取整數；多數幣別顯示兩位小數；定義為三位小數的幣別顯示三位。
  • 匯率時間戳記取自匯率端點回傳的值（若有）。
