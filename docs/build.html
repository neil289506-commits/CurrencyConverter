CMake 3.21+、C++17、Qt 6.4+(Widgets、Network);主要目標 Windows / MSVC 2022 / Qt 6.11。

下載或建置

最新版本

⬇ 前往最新 Release 所有版本

建置指令

cmake -S . -B build -DCMAKE_PREFIX_PATH="C:/Qt/6.11.0/msvc2022_64"
cmake --build build --config Release
# 輸出:build/Release/CurrencyConverter.exe

專案啟用嚴格警告:MSVC 用 /W4 /permissive- /utf-8,其他編譯器用 -Wall -Wextra -Wpedantic。
