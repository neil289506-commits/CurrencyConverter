試玩:匯率換算

核心功能

一眼看懂 CurrencyConverter 能做什麼。

🔎

可搜尋的幣別選單

以代碼或名稱搜尋,不分大小寫;常用幣別也有中文名稱。

⇄

一鍵交換

快速對調來源與目標幣別。

⏱

自動更新

視窗在前景時,每 60 秒更新匯率。

🗄

60 秒快取

減少不必要的網路請求。

🔢

依幣別格式化

零小數位幣別(例如日圓)取整數,三小數位幣別顯示三位。

📴

離線備用清單

幣別清單載入失敗時使用內建清單。

💾

記住上次設定

下次啟動沿用幣別與金額。

🌙

深色介面

精簡的深色主題。
